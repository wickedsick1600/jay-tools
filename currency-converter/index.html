    Before you exchange money

    These are daily reference rates for estimates, not a guaranteed transaction quote. Banks, cards, cash desks, and transfer services may use their own rate and add fees, so the amount you actually receive can differ.

    How to use this

    1. Enter an amount and choose its currency.
    2. Add, change, or remove destination currencies. Results update locally as you type.
    3. Check the reference date shown below the results, then copy the full comparison when you are ready.

    About the rates

    Rate data comes from the no-key Frankfurter exchange-rate API, which gathers reference rates from central banks and other official institutions. Juankit saves the latest successful rate set in this browser so the converter can keep working if a later refresh fails. A saved set is always labeled with its actual rate date.
