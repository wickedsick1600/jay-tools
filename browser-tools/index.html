What “browser-based” means

A browser-based tool uses the capabilities already built into Chrome, Firefox, Safari, or Edge. For many jobs, the browser can read, transform, and export a file without sending the file to an application server.

Fewer uploads

Local file processing keeps supported PDFs, images, audio, and text on the device you are using.

No installation

Open a page and use it. There is no desktop package, browser extension, or account setup.

Focused workflow

Each page handles one practical task, so you do not have to navigate a full editing suite.

Which tools keep data on your device?

Juankit does not use third-party analytics or advertising scripts. The exact network behavior depends on the job, so here is the plain-language version.

Local file and text tools
The PDF, image, audio, JSON, regex, diff, password, word-counting, and generator tools do their work in your browser. Selected files and entered content are not uploaded to Juankit.
Currency conversion
The currency converter downloads a public reference-rate dataset. It does not include your amount or selected target currencies in that request.
YouTube replay
The replay tool uses an embedded YouTube player, so YouTube receives the normal requests needed to load and play the video.
Feedback
The optional feedback form sends the information you enter through the site's hosted form. See the privacy policy for the full site explanation.

Questions about free browser tools

Can I edit a PDF online without uploading it?
Yes. Juankit's PDF Editor loads the document in your browser, applies annotations locally, and downloads the edited copy to your device.
Does the image converter upload my photos?
No. The Image Converter & Compressor uses browser image APIs to create the selected output format locally.
Do these online tools work on a phone?
Most tools use responsive layouts and work in current mobile browsers. Large PDFs, image batches, or audio files may work better on a desktop because processing uses the device's available memory.
Do I need to create an account?
No. Juankit tools do not require signup, a subscription, or a browser extension.
Are the tools really free?
Yes. The live tools are free to use. Optional Ko-fi and PayPal links support the project but do not unlock features.
