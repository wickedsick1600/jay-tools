What counts as a word?

The counter uses your browser's language-aware text rules, so it works with languages that do not always separate words with spaces. Joined forms such as don't are normally one word. Character counts use visible characters where browser support allows, so an emoji made from several code points is counted once.

Sentence and word boundaries can vary slightly by language and browser. Reading and speaking times are estimates, not deadlines.
